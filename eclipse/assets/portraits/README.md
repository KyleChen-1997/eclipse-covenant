# 百人名录立绘 · V11

本轮为百人名录中的 77 位新增契约者生成独立立绘：N 19、R 19、SR 18、SSR 17、UR 4。保留原有 23 位角色的美术。

- 工具：内置 `image_gen.imagegen`，每个角色独立生成，没有使用 CLI 或占位图替代。
- 原图：`../heroes/<角色 id>-v11.png`，均为 1024 × 1536 PNG。
- [生成清单与完整最终提示词](manifest-v11.json)：包含角色设定、模型配色、生成源路径、文件尺寸和 SHA-256。
- 游戏接入：`roster.js` 的 `art` 字段用于图鉴、详情、召唤、编队头像及技能切入画面。
- 新增 21 套 SSR / UR 动态绑定；全游戏合计 32 位 SSR 及以上角色使用局部头部、发丝、衣摆和眼睑动画。
- 独立图片使用浏览器原生延迟加载，动态图层仅在进入视野后加载和绘制。

本地验收页：`/tests/portraits-v11.html` 可分页检查全部 77 张图片；`/tests/living-v11-preview.html` 可检查新角色动态像素、静态对照和弹窗暂停。测试页不会包含在 Actions 的 Pages 发布产物内。
